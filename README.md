# 雷爪獅訓練 App / PWA v3

延續使用者提供的 v2，以原有腹肌、無繩跳繩有氧、兩個 7.5 kg 啞鈴全身訓練為基礎，加入逐組休息、DOMS 調整與可恢復的訓練流程。純靜態網站，無後端、帳號或分析追蹤。

正式網址：<https://leijoa.github.io/leiworkout/>

## 開始使用

1. 選擇「腹肌／有氧／全身」，查看完整流程與預估時間。
2. 按「確認狀態，開始訓練」，回報**目前**的痠痛程度。
3. 計時動作及休息會自動開始、銜接。次數動作完成後，按「完成這一組」；左右動作須兩側都完成。
4. 可暫停、上一個或跳過。上一個會回到該步驟起點並暫停，原完成標記清除。提早結束也能儲存實際完成的部分。
5. 完成或結束後記下當下感覺，按「儲存這次訓練」。隔天再到「紀錄」回報 DOMS，可重複更新。

**切換 App、鎖屏或頁面進入背景時，會自動暫停。** 返回後須按「繼續」。不承諾背景計時／背景語音；這能避免 iPhone 漏播提示卻繼續換動作。

## iPhone 加入主畫面與離線

1. 在 Safari 開啟正式網址，點分享 →「加入主畫面」。
2. 從主畫面啟動 App，先保持連網直到頁首顯示「離線已備妥」。
3. 三套菜單、計時與本機紀錄之後可離線使用。首次開啟需要連線；語音能否離線使用，取決於裝置是否已安裝相應聲音。
4. 第一次訓練前，先在首頁「試聽韻東」，或在設定中「測試聲音與震動」。確認音量，並讓畫面保持前景。

語音使用瀏覽器／裝置的中文聲音，不是自訂配音或聲音複製。iPhone 不支援網頁震動；其他裝置也可能依系統設定停用震動。常亮需要瀏覽器支援、HTTPS 與可見頁面，低電量或系統政策可能拒絕；訓練頁會顯示實際取得結果。

App 發現更新時會顯示更新提示。請先結束並儲存訓練，再按「更新 App」，避免中途切換版本。

## 韻東角色與自訂頭像

韻東會依動作、休息、剩十秒與完成狀態提供文字及語音提示。預設使用「韻東」文字頭像。

在「設定與安裝 → 你的教練頭像」選擇自己的照片，即可替換首頁及訓練頁頭像。圖片會在裝置端縮成 256 × 256；只存本機，不會上傳到 GitHub。使用者這次提供的玩偶照片未包含於公開網站或專案 ZIP。

## DOMS 規則與限制

| 目前狀態 | 下一次訓練 |
| --- | --- |
| 沒有痠痛 | 維持基本份量，不自動增加重量或次數 |
| 微痠 | 工作秒數／次數約 80%，四捨五入為整數 |
| 明顯痠痛 | 優先休息；若進行則約 60%，每個動作最多一組 |
| 疼痛／動作受限 | 不啟動訓練，建議休息與必要評估 |

暖身、休息、恢復走動與收操不縮短。首頁用最新 24 小時內回報預覽份量；疼痛回報不會因時間經過自動清除。**每次開課都必須重新回報現在的全身狀態**，以新回報建立當次固定菜單；不同訓練類型不會繞過疼痛狀態。

當下「輕鬆／剛好／吃力／不舒服」與隔天痠痛分開記錄，當下累不會被誤當成 DOMS。百分比是保守的產品規則，不是經臨床驗證的個人化處方；痠痛也不是訓練成效指標。若有尖銳疼痛、嚴重或持續疼痛、明顯腫脹，停止運動並尋求醫療評估。7.5 kg 過重時請用輕重量、徒手或跳過，不能靠單手交替假裝重量變輕。

健康資訊參考：[Cleveland Clinic：Delayed Onset Muscle Soreness](https://my.clevelandclinic.org/health/diseases/delayed-onset-muscle-soreness)。

## 紀錄、備份與 v2 相容

- 完成、跳過、未完成分開儲存；全部跳過不會標成完成整堂。
- 時間是實際進行時間，排除暫停。次數動作時間以開始到手動完成計；預估時間以每下約三秒加總，與 v2 原先固定標示的分鐘数可能不同。
- 一般紀錄存在 `localStorage` 的 `leiworkout_v3`，本機無雲端同步。相同瀏覽器分頁重新整理後可從暫停狀態恢復進度；進行中快照存在 `sessionStorage`，關閉分頁／瀏覽器可能遺失尚未儲存的進度。
- 同一網站來源上的舊 `leiworkout_history` 會唯讀轉入 v3；保留舊 key，舊紀錄不捏造逐步完成資料。不同網址／瀏覽器的資料不會自動搬過來。
- 在紀錄頁「匯出備份」下載 JSON。「匯入備份」會依 ID 合併 v3 紀錄與回報，保留原有項目及目前設定，不清空資料。備份也可能包含你自行設定的頭像，請自行保管。
- 遇到壞 JSON、瀏覽器禁止儲存或空間不足，會顯示警示，不自動清空或覆蓋損壞資料。可匯出記憶體中的資料；損壞資料模式會另嘗試下載原始資料以供修復。瀏覽器若封鎖多檔下載，請允許該次下載。匯入不是自動修復損壞資料的功能。
- 關閉／清除網站資料、換裝置及私密模式的資料生命週期由瀏覽器控制；請先匯出備份。

## 本機執行

不要直接雙擊 `index.html`：ES modules 與 Service Worker 需要 HTTP(S)。在專案資料夾執行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:8765/>。正式部署不需要 Node 或建置步驟。

## GitHub Pages 部署

專案根目錄放在 `Leijoa/leiworkout` 的 `main` 分支；Settings → Pages → Deploy from a branch → `main`、`/ (root)`。`.nojekyll` 避免額外模板處理。網站使用相對路徑，適用 `/leiworkout/` 子路徑。

每次修改任何網站資源，**同步更新 `sw.js` 的 `VERSION`**。新版先完整快取，等待使用者在無進行中訓練時按更新才取代舊版。Cache 名稱含網站 scope，只清理本 App 自己的版本，避免干擾同網域其他 PWA。

GitHub 文件：[設定 Pages 發布來源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 開發與驗證

環境：Node.js 22 以上；瀏覽器檢查用 Playwright 1.64.0。正式網站無執行時第三方依賴、CDN、遠端字型或外部圖片。

```sh
npm test
npm ci
npx playwright install chromium webkit
```

開啟上面的本機伺服器後，在另一個終端機執行：

```powershell
$env:APP_URL = 'http://127.0.0.1:8765/'
$env:SCREENSHOT_DIR = './test-results/screenshots'
npm run test:browser
```

Linux/macOS 可使用 `APP_URL=http://127.0.0.1:8765/ SCREENSHOT_DIR=./test-results/screenshots npm run test:browser`。

測試涵蓋：三套訓練資料、DOMS 四級、預覽及實際流程、十秒跨越、停止／重啟競態、暫停、上一個、跳過、各套完整結束、部分紀錄、重新整理恢復、備份合併、v2 移轉、毀損資料保護、儲存 API 例外、本機頭像、手機寬度及離線重新載入。

瀏覽器測試使用加速時鐘；WebKit 測試不是實體 iPhone。iPhone 真機安裝、實際聽感、靜音模式、常亮持續性與作業系統省電行為仍需在使用者手機確認。

## 檔案與來源

- `index.html` / `style.css`：手機優先介面與無障礙控制。
- `app.js`：畫面、計時互動、聲音、常亮、紀錄與離線狀態。
- `core.js`：從 v2 保留的三套菜單、DOMS 調整與純計時器。
- `storage.js`：資料驗證、v2 移轉、合併及資料保護。
- `sw.js` / `manifest.webmanifest` / 原 v2 PNG 圖示：PWA。
- `tests/`：可重跑的核心、資料與瀏覽器檢查。
